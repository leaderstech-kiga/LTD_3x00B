## 1. 이번 세션에서 한 일

### 1.1 시료 편차 대응 — Per-unit Calibration 설계 및 구현

**문제:** 7개 시료의 12% 연기 측정값 편차가 100~250 (2.5배), clean air 측정값 편차 6~75 (12배) → 단일 고정 threshold로 모든 시료 커버 불가.

**해결:** 시료별 baseline(offset) + gain_Q8 두 값을 내부 DataFlash(0x3000)에 저장.

```
Si_Da_norm = ((Si_Da_raw - baseline) × gain_Q8) >> 8
gain_Q8    = (200 × 256) / (Si_Da @ 12% smoke - baseline)
```

**검증 결과:** 7개 시료 모두 12% 연기에서 보정 후 199로 수렴.

### 1.2 3-Step 초기화 절차 (기존 제품 패밀리와 통일)

| Step | 트리거 | 동작 | LED |
|------|--------|------|-----|
| 1. Flash erase | SW2 누른 채 부팅 | DataFlash 0x3000 page erase | LED_G↔LED_R 교차 3회 (250ms씩) |
| 2. Baseline 캡처 | DataFlash 비어있음 + SW2 1회 누름 | 현재 ADC값 baseline으로 저장 (gain=256) | LED_G 0.5초 깜박 → 누름 → 1초 점등 |
| 3. Smoke 보정 | Normal mode + SW2 < 500ms 짧게 누름 | 10초 대기 + 5초 측정 + gain 계산/저장 | LED_R 10s 점등 → 5s간 0.5초 깜박 |

상수:
- `CALIB_REF_DELTA = 200` (12% 연기에서 normalize 목표값)
- `CALIB_ALARM_THRESHOLD = 160` (= 200 × 80%, 알람 트리거)
- `CALIB_MIN_DELTA = 30` (Phase 3 거부 임계)
- `CALIB_SHORT_PRESS_MS = 500` (short press 상한)
- `CALIB_SMOKE_BLINK_MS = 500` (LED_R 깜박 주기)

### 1.3 UART 출력 게이트

`uart_debug_mode == uart_debug_On`일 때만 ADC 측정마다 `Uart_Out()` 호출. 양산 모드(`Debug_Off`, 기본값)에서는 `Get_Bat_Voltage_cV` + `Uart_Out` 둘 다 skip → 전력 절감.

main.c line 136에서 전환:
```c
uint8_t uart_debug_mode = Debug_Off ;   // 양산
uint8_t uart_debug_mode = Debug_On ;    // 시험
```

### 1.4 버그 fix
- `calib.c` line 55의 C247 컴파일 에러 (`code *` 포인터 non-constant initializer) → 베이스 포인터를 상수 `CALIB_ADDR`로 고정 + offset을 배열 인덱싱으로 처리.

## 3. calib 모듈 공개 API

| 함수 | 역할 | 호출 위치 |
|------|------|----------|
| `calib_load()` | DataFlash 읽기 + 검증 | calib_boot_init 내부 |
| `calib_save(b, g)` | 페이지 erase + write + 검증 | calib_boot_init, calib_run_smoke_short, calib_erase_with_animation 내부 |
| `calib_apply(raw)` | 정규화 (((raw-base)×gain)>>8) | main loop ADC 블록 |
| `calib_erase_with_animation()` | Step 1: LED 교차 + page erase | main() boot |
| `calib_boot_init()` | Step 2: load 또는 SW2 누름으로 baseline 캡처 + needs_smoke 플래그 세팅 | main() boot |
| `calib_run_smoke_short()` | Step 3: 10s 대기 + 5s 측정 + gain 계산/저장 | main loop short press 시 |

전역:
- `g_calib_baseline`, `g_calib_gain_Q8`, `g_calib_valid`, `g_calib_needs_smoke`

## 6. 알려진 제약

1. **첫 baseline 캡처 = 사용자 책임** — Step 2에서 SW2 누르는 순간의 ADC가 baseline으로 잠김. 누르기 전 clean air 보장 필요.
2. **Smoke 재보정 = Step 1부터** — 한 번 성공 후 g_calib_needs_smoke=0 되어 short press 무력화. 재보정 시 flash erase 후 baseline 재캡처부터.
3. **Short press 최소 200ms** — WDT wake 간격(~0.192s) 때문에 너무 짧은 press(100ms 이하)는 놓칠 수 있음.
4. **Step 3 15초 블로킹** — Smoke cal 중 메인 루프 정지. 화재 감지 안 됨.

## 8. 빠른 참조 — UART 출력 형식

uart_debug_mode = Debug_On 상태에서 ~8초마다 출력:

```
Visu_MODE: Bat:0299 Si_Off:0000 Si_On:0000 Si_Da:0000 Du_Off:00XX Du_On:00XX Si_Da:0190 Norm:0199 Base:0019 Gain:0299 Cv:0001
```

해석:
- `Bat:0299` = 2.99V
- 앞쪽 `Si_*` (3개) = 0000 (Dust_ADC_1AMP 미호출)
- 뒤쪽 `Du_*` + `Si_Da:` = Dust_ADC_2AMP 결과
- `Norm:` = calib_apply 결과 (160 초과 시 fire counter ↑)
- `Cv:0001` = DataFlash valid record load 성공
- `Cv:0000` = 캘리브레이션 기본값(baseline=0, gain=256) 사용 중
