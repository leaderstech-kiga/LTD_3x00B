# LTD-3x00B 작업 세션 정리 (2026-05-30)

> 다음 세션 이어가기용 메모. `session_2026-05-29.md`(캘리브레이션 설계) 이후의 작업.
> 대상: A96L416 펌웨어 (Keil C51). 디버거로 DataFlash/부팅/메인루프 브링업 중.

## 1. 이번 세션에서 한 일 (요약)

1. **DataFlash 읽기 버그 fix** — `calib_read_word`가 `code` 포인터(MOVC)로 0x3000을 읽어 항상 0 리턴. UM 4.4에 따라 DataFlash는 DPTR(XDATA) 접근이라 `xdata` 포인터로 수정. → 디버거에서 erase→write→read-back 4개 검증 통과 확인 완료.
2. **DFMBUSY 완료 대기** — `calib_wait_df_ready()` 추가, erase/write 후 폴링 뒤 read-back.
3. **부팅 절차 재설계** (STEP 1/2-1/2-2 + STEP 3 보정함수).
4. **`Uart_Out_Text` 버그 fix** — `USART_SendDataWithPolling(&send_data, ...)` → `send_data` (포인터의 주소가 아니라 버퍼 자체). `main.h`의 `extern Flash_Read_Fail[19]` 타입 누락(`uint8_t`) 보완.
5. **메인 루프 STEP 1~5 구현** (레거시 상태머신 완전 대체).
6. **저전압 알람 구현** (이전 세션의 미해결 항목 — Bat_Low 빈 본체 + Bat_mode 미설정 문제 해결).
7. 문서: `main_loop_design.md` 신규, `calibration_design.md` rev4 갱신.

## 2. 부팅 절차 (calib.c / calib.h / main.c)

- **STEP 1** `calib_step1_boot_led()` — LED_G+LED_R 0.2초 동시 점등.
- **STEP 2-1** `calib_erase_with_animation()` (SW2 누른 채 부팅) — 홀드 중 G/R 0.2초 교차 → release 시 DataFlash erase → RAM 기본값(baseline=0,gain=256) → `Dust_ADC_2AMP()` 1회로 clean-air baseline 캡처 → `calib_save(baseline,256)`, `g_calib_needs_smoke=1`. 성공 LED_G 5회/실패 LED_R 5회 점멸.
- **STEP 2-2** `calib_boot_init()` (SW2 안 누름) — `calib_load()`로 baseline/gain 갱신.
- **STEP 3** `calib_run_smoke()` (메인루프, SW2 hold & needs_smoke=1) — LED_R + release 대기 → 시료 투입 5초(LED_R 0.2초 깜박) → 0.5초 깜박 5회 측정 → delta 판정.
  - `delta < CALIB_MIN_DELTA(=50)` → 거부, LED_R 빠른 깜박 5초, `needs_smoke=1` 유지(재시도).
  - `delta ≥ 50` → `gain_Q8=(200<<8)/delta` → save. 성공 시 `needs_smoke=0`.

**핵심 상수**: `CALIB_MIN_DELTA=50`(7개 시료 delta 최소 90 → 전부 통과. 100이면 시료 3·5·6 거부됨). `CALIB_REF_DELTA=200`, `CALIB_ALARM_THRESHOLD=160`.

**7개 시료 시뮬레이션** (delta_min=50): 7/7 전부 보정 성공, 12% 연기에서 norm≈199 수렴, 9.6%에서 ≈159(알람 직전).

## 3. 메인 루프 STEP 1~5 (main.c `while(1)`)

기준 동작은 `wdt_periodic_v3.md`(0.192초 wake, system_count 모듈로). 레거시 블록(In_Fire_al_mode 상태머신, fire_count, 수동 화재테스트, Al_Stop_mode, EMO, 빈 Bat_Low) **완전 제거**.

| STEP | 주기 | 동작 |
|------|------|------|
| 1 화재 감시 | 42 wake (~8.06s) | `calib_apply(Dust_ADC_2AMP())`≥160 → 예비(0.2초 깜박 4회/4초) → 평균≥160 → 화재(EMR_IO 출력 high, FIRE음성 ×3 0.3초간격 + 재확인 0.25초단위 4회/2초를 연기 해제까지 반복) |
| 2 LED+배터리 | 진입 전 1회 + 292 wake (~56s) | LED_R 0.2초 점멸 + 배터리 체크(265/275cV 히스테리시스) |
| 3 Low-bat 음성 | 진입 즉시 + Low 유지 시 1458 wake (~280s) | `Play_Clip(AUDIO_CLIP_LOWBAT)` 1회 |
| 4 외부 연동 | 매 wake | EMR_IO(P10) 입력 high → FIRE ×3(0.3초), LED_R OFF, 2초 대기 |
| 5 상태확인(SW2) | 매 wake | needs_smoke=1 → 보정 진입 / =0 → FIRE ×1(재생 중 LED_R 0.2초 깜박) |

**화재/음성 LED**: `Play_Clip`은 ~3초 블로킹이나 오디오가 Timer1 ISR로 백그라운드 재생되어 EA가 켜져 있음 → **Timer2 ISR로 LED_R을 0.2초 주기 깜박**(STEP1 음성·STEP5). 먼지 ADC 측정 구간은 인터럽트 간섭 방지로 Timer2 끄고 직접 깜박.

**헬퍼**: `loop_wait_ms`, `fire_confirm_avg(half_ms,toggles)`, `play_fire_burst(with_led)`, `fire_led_blink_start/stop`, `battery_check`.

## 6. 알려진 제약 / 주의

1. 화재 발생 루프는 연기 해제까지 블로킹(배터리/SW2/외부연동 미서비스 — 화재 우선).
2. `Al_Stop_mode`/`In_Fire_al_mode`는 제거됨 — `TIMER2_Int` ISR의 해당 참조는 진입 경로 없어 비활성(dead, 무해).
3. baseline 캡처는 STEP 2-1 release 순간의 clean-air 보장이 사용자 책임.
4. 빌드 미검증 상태 — Keil에서 반드시 Rebuild 확인.
